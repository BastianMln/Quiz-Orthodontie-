# Quiz ODF

Application personnelle de QCM, installable (iPhone, Mac) et utilisable hors ligne.

- Le site publié (branche `main`) ne contient que le code de l'app.
- Le contenu et la progression sont sur la branche `data`, **chiffrés** (AES-256-GCM, clé protégée par mot de passe). Sans le mot de passe, ils sont illisibles.
